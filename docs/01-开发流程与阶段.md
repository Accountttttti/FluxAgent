# 开发流程与阶段

> 项目：复刻 HKUDS/nanobot（个人 AI agent 框架），并做 UI 优化 + 前端性能优化。
> 目标：产出可投实习的作品集 + 一套教学笔记。

## 总体策略

先打通「前后端 + 三项优化」的**最小全栈闭环**，再往 agent 方向加深。小步快跑，每一阶段结束都保证能跑起来。

## 阶段 0 — 环境与研究

- 拉取 nanobot 源码，读懂它的架构（后端结构、WebUI 如何与后端通信、OpenAI 兼容 API）。
- 产出：《nanobot 架构拆解》笔记。
- 搭建本地开发环境（Python 后端 + React 前端）。

## 阶段 1 — 最小全栈闭环（MVP）

**后端**：自己写一个最简 Python 后端（FastAPI），内部调用 OpenAI 兼容接口（OpenAI / Ollama），用 SSE 流式吐给前端。

**前端**：React + TypeScript + Vite，落地三项优化：
1. zustand + requestAnimationFrame 流式渲染
2. markdown 解析（react-markdown）
3. IndexedDB 本地持久化（Dexie.js）

**验收标准**：发消息 → 流式回复 → 存进 IndexedDB → 刷新页面历史还在。

## 阶段 2 — agent 核心

- 工具调用（function calling）
- 记忆（短期 + 长期）
- 多会话管理

## 阶段 3 — 进阶能力（按需，可能简化）

- MCP
- 多 agent 工作流
- 自动化

## 阶段 4 — 打磨

- UI 重设计
- prompt 库整理到根目录
- 教学文档 + 面试准备
