## 项目怎么分层讲（别一次倒完）

1. **它是什么**：AI agent，不是 chatbot。区别是 agent 会「调用工具干活」。
2. **后端怎么实现 agent**：LLM + function calling + 循环（模型决定调工具还是直接答，循环到答完）。
3. **前端亮点**：流式渲染（50ms 节流 + React.memo）、工具调用可视化、IndexedDB 持久化。
4. **进阶**：技能层、记忆系统、多 agent、定时任务、MCP。

## 高频问题 + 回答要点

1. **什么是 AI agent？和 chatbot 有什么区别？**
   chatbot 只会说话；agent 会「动手」——调用工具、读写文件、定时干活。本质是「LLM + 工具 + 循环」。

2. **function calling 是怎么工作的？**
   把工具描述成 JSON schema 给模型，模型输出「我要调哪个工具、什么参数」而不是直接答；后端执行工具、把结果塞回对话，模型再决定下一步。循环直到模型不再调工具、直接给最终文字。

3. **流式是怎么实现的？为什么用 SSE 不用 WebSocket？**
   后端 `stream=True` 边生成边 yield，前端 `fetch` 读 `ReadableStream` 逐段解析。SSE 是单向流，够用且简单；WebSocket 是双向长连接，适合服务端主动推送、中止生成等复杂场景。先做 SSE 够用。

4. **流式渲染卡顿怎么优化？（重点，参考 docs/09）**
   攒 buffer + `requestAnimationFrame` + 50ms 节流；`React.memo` 隔离历史消息，只有当前消息重渲染。

5. **markdown 怎么渲染？怎么防 XSS？**
   react-markdown + rehype-sanitize 消毒（白名单过滤）+ rehype-highlight 代码高亮。

6. **本地持久化怎么做的？**
   IndexedDB（Dexie 封装），存会话 + 消息，刷新 / 切会话不丢。

7. **长期记忆怎么做？**
   `MEMORY.md` 注入系统提示词 + `history.jsonl` 历史检索 + 「整理记忆」用 LLM 把对话提炼成记忆 + git 版本化。

8. **多 agent 是什么？**
   主 agent 派一个 subagent 独立完成子任务，它有独立上下文、独立跑循环，最后把结果文本交回。防止无限嵌套：subagent 拿不到 subagent 工具。

9. **MCP 是什么？怎么接入的？**
   统一的外部工具协议。我们用 stdio 连 calc + filesystem 两个 server，启动时 `list_tools` 注册进工具表，工具名加前缀隔离命名空间。

10. **为什么这个项目选 React，而你熟 Vue？**
    复刻对象 nanobot 的前端生态是 React，所以跟着用；我熟 Vue 3，两者思路相通——组件、响应式、状态管理都能类比（比如 zustand 之于 Vue 的 Pinia）。
